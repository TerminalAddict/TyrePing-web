Install TyrePing.

Download the Android APK, add your vehicle and connect your compatible sensors. Google Play distribution is planned; for now, installation and updates are manual.

Before you begin

  • Android 9 or later on a phone with Bluetooth Low Energy.
  • Compatible BLE tyre-pressure sensors. Your phone alone cannot measure tyre pressure.
  • Your vehicle’s recommended cold tyre pressures, so you can choose appropriate alert thresholds.

Preview release: v0.5.0 is a GitHub pre-release. TyrePing is under active development, and some monitoring scenarios still need physical hardware validation. Prefer a stable build? Use the latest stable release.

1. Download the signed APK

On your Android phone, open the official v0.5.0 release and select TyrePing-v0.5.0.apk under Assets. Or use the download button on this page. The download is hosted on GitHub.

For an optional integrity check, compare the downloaded file’s SHA-256 hash with the release’s SHA256SUMS.txt. A matching hash confirms that your file matches the published download.

2. Open and install

Open the APK from your Downloads folder or your browser’s download list. If Android asks, enable Allow from this source for the browser or file manager opening it, then return to the installer and choose Install.

The exact settings label varies by phone. After installing, you can turn that permission off again. A managed work device may prevent manual installation.

3. Allow Bluetooth access

Open TyrePing and switch on Bluetooth. Grant the permissions requested by your version of Android:

  • Android 12 and later: Nearby devices access for Bluetooth discovery and connections.
  • Android 9–11: location permission is needed by Android for Bluetooth discovery. Automatic background discovery on Android 10–11 may also require “Allow all the time”. TyrePing does not record GPS location.
  • Notifications: allow these when requested so monitoring status and alerts can be shown.

4. Add a vehicle and bind sensors

Create a vehicle, choose its layout and assign a compatible sensor to each tyre. Use QR-code binding where supported, or select a favourite sensor. Check that each reading belongs to the expected tyre and that its “last seen” time is updating.

Choose your pressure and temperature units, then set low/high-pressure and temperature limits. Use your vehicle and tyre manufacturers’ recommendations, rather than the illustrative values shown on this website.

5. Choose how to monitor

Use the vehicle screen to check readings, or start manual background monitoring. Automatic ride monitoring can watch for a paired Bluetooth accessory or a BLE beacon and start monitoring the selected vehicle.

One vehicle can be watched automatically at a time. Watching keeps a foreground service running and uses battery. After a reboot or force-stop, reopen the app and start watching again. Android battery restrictions and sensor reception can affect results; real-world accessory, beacon and screen-off validation is still in progress.

Updating TyrePing

Check the GitHub releases page for newer APKs. Download and install the newer signed release over your existing installation. Android normally retains app data when the application ID and signing certificate match.

The debug build is a separate app with separate data. TyrePing also has its own application ID and can be installed alongside the original TPMS Advanced app.

Sensor compatibility

The app supports selected Bluetooth advertisement formats used by Sysgration, Pecham, Bekubee/HRTPMS and Wicarlink/LYTPMS, plus related compatible sensors. A brand name alone does not establish compatibility.

Many factory-installed TPMS systems use radio protocols your phone cannot receive. Check the sensor’s BLE advertisement format against the project documentation before purchasing hardware.

If readings do not appear

  • Check Bluetooth is on and the app has its requested permissions.
  • Check sensor compatibility, battery and proximity to the phone.
  • Confirm each sensor is assigned to the correct tyre and vehicle.
  • Check Android’s background and battery restrictions if readings stop with the screen off.

Still stuck? Open a GitHub issue with your Android version, sensor model and a description of what you see. Avoid posting personal information or credentials.

Keep your normal tyre checks. TyrePing is advisory. Use a calibrated gauge, inspect tyres regularly and follow manufacturer guidance. Experimental leak detection is disabled by default and has not yet been validated on a real ride.
