Website privacy.

What happens when you visit tyreping.com, and where to learn about the Android app.

Updated 17 October 2026

This website

Tyreping.com is a static website. It has no account system, contact forms, analytics scripts, advertising or third-party embeds. It does not set cookies or use browser storage. Fonts, images and scripts are served from this website.

The screenshot selector displays app screenshots in your current page. It does not connect to Bluetooth devices or send sensor readings anywhere.

Hosting and access logs

Requests to the website are processed by its hosting server. Standard web-server logs may contain your IP address, requested URL, time of request, browser information and referring page. These logs support website operation and troubleshooting.

APK downloads and external links

APKs and release notes on the downloads page are hosted on tyreping.com. Download requests are handled by the same hosting server as this website.

External websites linked from this site have their own terms and privacy information.

If you choose store installation, Google Play handles the purchase, download and update process under its own terms and privacy information.

The Android app

This page describes the website. The Android app is a separate product. Review its permission settings and the release notes for your build alongside this website information.

Bluetooth discovery requires Nearby devices permission on Android 12+, or location permission on older Android versions. The project states that TyrePing does not record GPS location. Background monitoring and notifications need their own permissions. See the install guide for setup details.

Installation help

See the installation and troubleshooting guide for help with permissions, sensor readings and background monitoring.
