Project acknowledgements

TyrePing’s Android application code is based on TPMS Advanced and includes additional code contributions and adaptations from Persistent TPMS. Both projects distribute this code under the Apache License, Version 2.0.

TPMS Advanced

Developed by Vincent Masselis and contributors.

TyrePing is an independent fork of TPMS Advanced. Its Android application foundation, Bluetooth Low Energy TPMS sensor support, vehicle layouts and core monitoring interface derive from this project.

Project source · Upstream Apache 2.0 licence · Contributors

Persistent TPMS

Developed by aveshev and contributors.

TyrePing incorporates additional code contributions and adaptations from Persistent TPMS, which is itself a fork of TPMS Advanced.
